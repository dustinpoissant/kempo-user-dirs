User Files

A private folder for each member, stored in the file library under users/. Nobody has one until they hold userdirs:access — normally by being added to the kempo-user-dirs:member group, which is the point where a paid tier would eventually hook in.

Spaces

Create a space

Only users who already hold userdirs:access appear here. Spaces are also created automatically the first time an eligible member opens theirs, unless the auto_provision setting is turned off.

Storage plans

A plan is a named allowance many spaces can share, so changing what a tier is worth is one edit rather than one per member. Leave a limit blank for unlimited — which is how this ships, so the feature works before anybody has decided what to charge for it.
